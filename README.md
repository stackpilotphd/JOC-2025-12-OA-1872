# JOC-2025-12-OA-1872
This repository contains instances and results for the The Generator Deployment Problem: Integrating Generator Routing and Cable-Trench Network Design in Emergencies.
This repository contains the benchmark instances, computational results, and executable source code associated with the paper.
The repository is intended to support reproducibility and facilitate future research on emergency power restoration, infrastructure resilience, vehicle routing, and network design.
